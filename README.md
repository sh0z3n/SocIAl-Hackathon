# Safe Bump - AI-Powered Pregnancy Health App

A comprehensive Flutter application for pregnancy health management with AI-powered health predictions and chat assistant.

## Features

- 🤖 **AI Health Predictor** - Local ML model for instant health risk assessment
- 💬 **AI Chat Assistant** - Get answers about pregnancy, menstrual health, nutrition, and exercise
- 📅 **Pregnancy Calendar** - Track your pregnancy journey
- 🏥 **Hospital Finder** - Find nearby hospitals and clinics
- 📚 **Health Articles** - Educational content about pregnancy
- 🏃 **Exercise Guide** - Safe exercises for each trimester
- 🍎 **Nutrition Tips** - Healthy food recommendations
- 📊 **Health Timeline** - Visualize your pregnancy progress

## Installation

### Download APK
- `app-release.apk` - Release build (25MB)
- `socai.apk` - Release build (25MB)

### Build from Source
```bash
flutter pub get
flutter build apk --release
```

## Dataset

The app includes Menstrual Health Awareness Dataset:
- Training Data: `Menstrual Health Awareness Dataset_Training Data.csv`
- Testing Data: `Menstrual Health Awareness Dataset_Testing Data.csv`

## Technology Stack

- Flutter/Dart
- Firebase Authentication
- Local ML Model (Health Predictor)
- AI Chat Service
- Google Maps Integration
